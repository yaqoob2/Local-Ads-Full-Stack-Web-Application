# 🚀 LocalAdsConnect – README

> A fast, mobile-first **Local Advertising Marketplace** that connects nearby customers to small service providers through **instant WhatsApp chat**.
> Clean UI, template-based ads, and subscription-driven featured placements.

---

## 🌟 What is LocalAdsConnect?

**LocalAdsConnect** is a web platform where local businesses and freelancers can post simple, beautiful ad cards and receive leads directly on WhatsApp.
No complex dashboards. No image uploads. Just **fast discovery + instant contact**.

---

## 🎯 Core Value Proposition

* **For Customers:**
  Find nearby services quickly and message providers instantly on WhatsApp.
* **For Providers:**
  Post a clean, professional ad in minutes and get real leads without learning social media ads.
* **For Admins:**
  Moderate listings, track performance, and grow subscriptions with clear KPIs.

---
### KEY FEATURES

### 🔍 Smart Discovery

* Category filters
* City / Area / Pincode search
* Clean card-based listings
* Fast mobile experience

### 💬 Instant WhatsApp Contact

* One-tap “Chat Now”
* Click tracking for performance metrics

### 🎨 Template-Based Ads (No Images Needed)

* 6 reusable UI templates
* Professional, gradient, promo, minimal, badge, and split styles
* Consistent design across the platform

### ⭐ Sponsored & Featured Placements

* **Growth** and **Business** plans get premium visibility
* Banner carousel (“Sponsored Spotlight”)
* Horizontal featured row
* Equal rotation between Growth and Business ads

### 🧾 Subscription Plans

* **Basic:** normal grid only
* **Growth:** featured row + better ranking
* **Business:** spotlight banners + top placement

### 🛡️ Moderation & Trust

* Admin approval flow
* Ban users
* Status badges (Approved / Pending / Rejected)

### 📊 Admin Analytics (KPIs)

* User growth
* Ads by category
* Views vs WhatsApp clicks
* Plan distribution
* Ads status & approval rate
* Top locations

---

## 🧪 Tech Stack

### Frontend

* **React + Vite**
* **Tailwind CSS**
* Axios (API client)
* Mobile-first UI

### Backend (already built)

* **Node.js + Express**
* **MongoDB (Mongoose)**
* JWT Authentication
* REST APIs

---

## 🔗 API Highlights

* **Auth:** `/api/auth/login`, `/api/auth/register`, `/api/auth/profile`
* **Ads:** `/api/ads`, `/api/ads/:id`, `/api/ads/myads`, `/api/ads/:id/click`
* **Meta:** `/api/meta/categories`, `/api/meta/templates`
* **Admin:** `/api/admin/ads/pending`, `/api/admin/users`
* **Location:** `/api/locations/pincode/:pincode`
* **Subscriptions:** `/api/subscription/plans`
